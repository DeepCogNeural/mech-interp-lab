## Experiment 03 — SAE features on the shattering × CCGP plane

![Five-seed shattering-dimensionality versus CCGP comparison of GPT-2 residual, SAE, reconstruction, and matched random-expansion codes](figures/01_shattering_vs_ccgp.png)

Caption — the sparse SAE code has SD **0.716 ± 0.013** versus **0.731 ± 0.010** for its width-, scale-, and L0-matched sparse random expansion; the paired difference is **−0.015 ± 0.017**, an honest null. Overall CCGP is near chance for every arm, while main-effect CCGP reveals a factor-decodability mismatch that confounds an interaction-only interpretation.

This is a representation/lens measurement, not a model intervention: the SAE never replaces GPT-2's residual stream in the forward computation. Full gates, dichotomy breakdown, controls, and caveats: [Experiment 03 writeup](writeup.md).
